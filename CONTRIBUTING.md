# Contribuindo

Obrigado pelo interesse. Este guia cobre o ambiente, os scripts e o que esperamos de um pull request.

## Ambiente

Requisitos: PHP 8.4 ou 8.5 e Composer 2.

```bash
git clone https://github.com/CodifyTech/asaas-sdk-laravel.git
cd asaas-sdk-laravel
composer install
```

Os testes usam `Http::fake`. Não é preciso API key, e nenhum teste deve chamar a API real.

## Scripts

| Script | O que faz |
|--------|-----------|
| `composer test` | Roda a suíte do PHPUnit. |
| `composer analyse` | Análise estática com PHPStan e Larastan. |
| `composer format` | Formata o código com Laravel Pint. |
| `composer format:check` | Verifica a formatação sem alterar arquivos. |
| `composer generate` | Regenera os arquivos gerados a partir do mapa de endpoints. |
| `composer generate:check` | Falha se algum arquivo gerado divergir do mapa. |
| `composer ci` | Roda `format:check`, `analyse`, `generate:check` e `test`. |

## Arquivos gerados

Boa parte do SDK é gerada a partir de `tools/endpoint-map.json` e da especificação oficial em `tools/asaas-openapi.json`. **Não edite à mão**:

- `src/Services/*Service.php`
- `src/Http/Requests/**`
- os models listados em `MapValidator::GENERATED_MODELS` (e seus `*List`)
- `tests/Services/*ServiceTest.php`
- `docs/services/*.md` e `docs/README-services.md`
- `resources/boost/skills/asaas-sdk-laravel/references/*.md`

Cada um traz um cabeçalho "Generated by ...". Para mudar esses arquivos, altere `tools/endpoint-map.json` ou o gerador em `tools/generator/` e rode:

```bash
composer generate
composer generate:check
```

Para atualizar a especificação oficial, rode `php tools/sync-spec.php` e revise o diff de `tools/asaas-openapi.json` e `tools/doc-pages.json`.

## Convenções

- Todo arquivo PHP começa com `declare(strict_types=1);`.
- Código, identificadores, comentários e testes em inglês. Documentação em `docs/` e mensagens ao usuário em português.
- Commits no padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0/): `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`. Mudança incompatível leva `!` (`feat!:`) ou o rodapé `BREAKING CHANGE:`.
- Nunca versione uma API key real, nem em testes ou fixtures.

## Checklist do pull request

- [ ] `composer ci` passa localmente.
- [ ] Testes novos ou ajustados cobrem a mudança.
- [ ] Arquivos gerados foram regenerados com `composer generate`, não editados à mão.
- [ ] README.md, `docs/ai-playbook.md` ou a skill em `resources/boost/skills/asaas-sdk-laravel/SKILL.md` foram atualizados se a superfície pública mudou.
- [ ] A seção `[Unreleased]` do CHANGELOG.md descreve a mudança.

Falhas de segurança não devem virar pull request público: siga o [SECURITY.md](SECURITY.md).
